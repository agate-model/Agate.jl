# Agate.jl

Agate.jl builds flexible and composable aquatic ecosystem models for Oceananigans.jl and OceanBioME.jl.

Scientific models are defined from structured components, named biological processes, and semantic parameter definitions. Agate resolves that model definition during setup into concrete, static tracer equations suitable for differentiable and accelerator-oriented runtime execution.

Start with the [Quick start](@ref), or begin defining a custom ecosystem with [Franks et al. (1986) NPZ](@ref franks_npz) and continue through the **Defining models** examples.
