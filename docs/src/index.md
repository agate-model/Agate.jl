# Agate.jl

Agate.jl builds flexible and composable aquatic ecosystem models for Oceananigans.jl and OceanBioME.jl.

Scientific models are authored from structured components, named biological processes, and semantic parameter definitions. Agate resolves that authoring graph during setup into concrete, static tracer equations suitable for differentiable and accelerator-oriented runtime execution.

Start with the [Quick start](@ref), or build a custom ecosystem through the [Model authoring](@ref) guide and its standalone runnable examples.
